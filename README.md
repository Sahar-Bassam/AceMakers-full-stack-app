#  AceMakers - Full Stack Laravel & Vue Application

AceMakers is a full-stack web application built using **Laravel** and **Vue 3 (Inertia.js)**.  
It combines authentication, a user management dashboard, and interactive Vue UI experiments in one project.

---

##  Overview

This project demonstrates how a modern full-stack application is structured, including:

- Backend authentication and user management (Laravel)
- Frontend UI built with Vue 3
- Dynamic component interaction and state handling
- Admin-style dashboard displaying real user data

---

## Features

### 🔐 Authentication System
- User registration and login
- Logout functionality
- Avatar upload support
- Session-based authentication

###  User Dashboard
- Displays registered users from database
- Paginated user list
- User avatar display with fallback image
- Registration date formatting

###  Vue UI Playground (Home Page)
- Dynamic font style switching using radio buttons
- Reactive UI updates using Vue 3 Composition API
- Component-based architecture
- Props and state communication between components

###  Navigation System
- Dynamic navbar based on authentication state
- Conditional rendering for guest vs logged-in users
- User avatar in navigation bar
- Dashboard & logout access for authenticated users

---

## Tech Stack

**Frontend:**
- Vue 3
- Inertia.js
- Tailwind CSS

**Backend:**
- Laravel
- MySQL / SQLite
- Laravel Authentication
